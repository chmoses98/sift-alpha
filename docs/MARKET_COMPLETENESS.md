# Market-archetype data completeness (RESEARCH_ONLY)

Generated by `python -m alpha_engine.input_research.data_foundation.market_completeness` from `research/input_research/data_foundation/verified_coverage.json` (agent verification, NOT human), the catalog and `rights_registry.json`; artifacts under `research/input_research/market_completeness/`. **This ranks DATA COMPLETENESS only. It says nothing about edge, profitability or model quality; modelling experiments remain PAUSED.**

Universe: 170 archetypes = 118 registered + 52 unregistered across 8 sports. Each lists catalog inputs with a role (primary / secondary / context). Market-derived benchmark inputs are excluded: they are not independent inputs. Input slots are counted per archetype, so one input shared by several archetypes is counted in each (slots, not distinct inputs).

**Five separate dimensions (Phase 9, extended Phase 10).** (1) *Predictive input completeness*: the score below, computed WITHOUT any market-metadata slot (Kalshi rules text, settlement/operational metadata, calibration benchmarks; see section 2b). (2) *Market semantics completeness*: whether the timestamped, contract-specific rules and settlement text each archetype's contracts need is captured (the `m.rules_text` slots: 144 slots, of which 134 are PRIMARY-role). Rules text is market semantics metadata, mandatory for settling a contract correctly but not an independent predictive sports input, so it is removed from the predictive denominator and never counted as predictive coverage. The catalog still lists it in every archetype and the baseline lock is unchanged. (3) *Rights-cleared availability*, reported separately for non-commercial research clearance and for commercial-use clearance: built-and-verified predictive slots whose sources carry an explicit data licence (`CLEARED_*` tiers); wrapper-only licences (nflverse CC BY over NFL upstream terms, `WRAPPER_ONLY`) and unresolved upstream terms count for neither. (4) *Prospective-capture gaps*: predictive slots that need vintages captured from now on.

Per predictive input (exactly one category): **FULL / PARTIAL / PROXY** = replayed + blind-verified builder; **DATA_IN_HAND** = real columns confirmed buildable, no builder yet; **FREE_ACCESSIBLE** = a permitted free source exists, nothing built or verified; **PROSPECTIVE** = needs capture from now on (no backfillable history, or point-in-time quarantined); **NO_FREE_SOURCE** = paid-only / none / sample-only / policy-blocked / blind-confirmed blocked; **CONTESTED** = blind rounds disagree on whether any permitted source exists. Score = (1.0 FULL + 0.5 PARTIAL + 0.25 PROXY) / required predictive inputs; critical score is the same over PRIMARY-role inputs. Ranking: critical score, then overall score.
