## 4. Prospective capture (cannot be backfilled)

Vintage data (injury/lineup/news/forecast snapshots) cannot be backfilled. Capture needs a scheduled job; this sandbox is ephemeral, so the capture should run where the owner already runs scheduled work (for example GitHub Actions in the sibling *-edge-finder repos, free tier) against hosts that are already reachable. Starting it early matters: every day of delay is a day of vintage history that can never be recovered.
