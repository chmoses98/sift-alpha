# Blind re-implementation brief: college football team-game features (strictly pre-game), 9 catalog inputs

Data (read-only, untrusted files: read with `python -I`, keep your scripts elsewhere): `BLIND/cfb/cfb/plays_<season>.parquet`, seasons 2014-2025 (concatenate in ascending season order; keep the file row order). Columns: game_id, season, pos_team, def_pos_team, home, away, period, down, distance, yards_to_goal, yards_gained, EPA, pos_score_diff_start, rush, pass, pass_attempt, sack, int, penalty_no_play, drive_id, drive_start_yards_to_goal, drive_result, rush_td, pass_td, pass_breakup_player_name, fumble_forced_player_name, start_date, neutral_site.
You may use numpy and pandas only. Output must match the reference to 1e-9 on every (game_id, team) row, NaN pattern included, so follow the formulas exactly. "Earlier" always means STRICTLY EARLIER DATES (daily batches): a game never sees a game of the same date. Sums called "league ... over earlier dates" run over ALL team rows (both teams of every game, all seasons) with date < d.

## 1. Plays, flags, per-team-game aggregates
Use plays with pos_team and def_pos_team not null. Games = distinct game_id (first row's season, home, away, neutral_site, start_date); game_date = the date given by the first 10 characters of start_date; drop games whose date is missing.
Per play (boolean unless noted; penalty_no_play == True excludes a play from rush/pas):
* rush = (rush == 1) & penalty_no_play != True; pas = (pass == 1) & penalty_no_play != True; scr = rush | pas.
* thr = 43, 38, 35 for period 1, 2, 3 and 28 for any other period (period missing -> the play is not non-garbage). ng = scr & |pos_score_diff_start| <= thr & EPA not missing.
* neu = scr & down in {1, 2} & |pos_score_diff_start| <= 7 & period <= 3; neu_pass = neu & pas; dropbacks = pas.
* havoc = scr & (sack == 1 | (rush & yards_gained < 0) | int == 1 | pass_breakup_player_name not null | fumble_forced_player_name not null).
* gtg = scr & (yards_to_goal <= 10 | (down in {3, 4} & distance <= 2)); gtg_run = gtg & rush; gtg_run_td = gtg & rush & rush_td == 1; gtg_pass_n = gtg & pas; gtg_pass_td = gtg & pas & pass_td == 1.
* rush_td_play = rush & rush_td == 1; pass_td_play = pas & pass_td == 1; first40 = scr & down == 1 & yards_to_goal <= 40.
Per (game_id, pos_team) sums ("offence of that team in that game"): scr, rush_ng (ng & rush), pass_ng (ng & pas), ng, epa_ng (sum of EPA over ng plays), epa_rush (EPA over ng & rush), epa_pass (ng & pas), neu_n (neu), neu_pass, dropbacks, havoc, gtg_n (gtg), gtg_run, gtg_run_td, gtg_pass_n, gtg_pass_td, rush_td (rush_td_play), pass_td (pass_td_play).
Drives: take plays with drive_id and drive_result not null and (scr or drive_result not null) i.e. every play with drive_id and drive_result not null; group by (game_id, drive_id, pos_team): plays = sum of scr, start = first non-null drive_start_yards_to_goal in file order, res = first non-null drive_result in file order, trip = max of first40 (as 0/1). Keep drives with plays >= 1. pts = 7 if res == 'TD', 3 if res == 'FG', else 0; td = (res == 'TD'); trip_pts = pts*trip; trip_pts_sq = trip_pts^2; trip_td = td*trip. Per (game_id, team) sums: n_drv (number of drives), drv_plays (sum plays), drv_start (sum of start, NaN skipped), drv_pts (sum pts), trips (sum trip), trip_td, trip_pts, trip_pts_sq. Teams with plays but no valid drive get 0 for these; (game, team) pairs with drives but no scrimmage plays get 0 for the play sums.
Team rows: for each game the home row (team = home, opp = away, hv = +1) and the away row (team = away, opp = home, hv = -1); hv = 0 on both if neutral_site is True (missing = False). Own columns o_<name> = the team's aggregates in that game; against columns a_<name> = the OPPONENT's aggregates in that game. Keep rows whose own and opponent aggregates both exist and o_scr > 0 and a_scr > 0. Row order and per-team sequence order: ascending (date, game_id); a team plays at most once a day. Output key (game_id, team) with team = the team-name string.

## 2. Ratings: cfb.off_ppa, cfb.def_ppa (columns ppa_off_{epa,rush,pass}_pre, ppa_def_{epa,rush,pass}_pre)
Responses per row: y_epa = o_epa_ng/o_ng if o_ng >= 20 else missing; y_rush = o_epa_rush/o_rush_ng if o_rush_ng >= 10 else missing; y_pass = o_epa_pass/o_pass_ng if o_pass_ng >= 10 else missing. Three independent walk-forward ridge fits, one per response.
Seasons ascending s_0, s_1, ...; cnt(s, team) = number of rows of that team in season s. Index set of season s_k: major teams = teams with cnt >= 8 in at least one of the two previous seasons that exist (for k = 0: cnt >= 8 in s_0 itself), keeping only those that appear (as team or opp) in season s_k, sorted ascending; every other team (as team or opp) maps to one pooled index OTHER placed last; T = number of major teams + 1. Parameters theta = [mu, h, o_1..o_T, d_1..d_T].
Prior means: mu = 0 always; k = 0: h = 0, o = d = 0; k > 0: h = previous season's final h; for each index (incl. OTHER) with a previous value o = 0.6 * previous final o, d = 0.6 * previous final d; otherwise 0. Penalties: 6 on every o, d, h; 1 on mu.
Observations of a season: each row with a non-missing response y gives x: mu 1, h hv, o_team 1, d_opp 1. At date d the training observations are those of the season on dates < d with weight 0.5^((d - obs date in days)/40). S = sum w x x', b = sum w x y; theta = (S + diag(pen))^-1 (b + pen*prior) (theta = prior with no observations).
Outputs for a row on date d: ppa_off_<m>_pre = o_team, ppa_def_<m>_pre = d_team (m = epa, rush, pass for y_epa, y_rush, y_pass). BOTH are the effects at the index of the row's OWN team (the `team` column), i.e. the team's own offence effect and the team's own defence effect; the defence effect at the opponent's index is NOT used as an output (it only enters the design x as d_opp for the observation). All six columns are NaN for every row of the first season. FINAL values of a season (next season's priors): after the season's last date's observations are added, multiply all weights by one extra day of decay (0.5^(1/40)) and solve once.

## 3. Rolling columns (per team along its own rows; "league" sums over earlier dates as above)
EWMA(x) = x.shift(1).ewm(halflife=6, min_periods=3).mean() per team (pandas adjust=True). wsum(x) = sum over k = 1..10 of 0.85^(k-1) * (the team's value of x k rows earlier, 0 if there is no such row; NaN values count as 0).
cfb.drives -> drv_n_pre = EWMA(o_n_drv); drv_plays_pre = EWMA(o_drv_plays/o_n_drv); drv_avail_pre = EWMA(o_drv_start/o_n_drv); drv_pts_pre = EWMA(o_drv_pts/o_n_drv); pa = EWMA(a_drv_pts/a_n_drv) (division by zero -> NaN); lg_dpts = (league sum of o_drv_pts)/(league sum of o_n_drv) (NaN when the denominator is 0). drv_pts_adj_pre = drv_pts_pre - (the opponent's pa in the same game) + lg_dpts. drv_exp_drives_pre = (drv_n_pre + the opponent's drv_n_pre)/2.
cfb.td_per_scoring_trip and cfb.scoring_trip_efficiency: lgn = league sum of o_trips (NaN if 0), lg_td = (league sum of o_trip_td)/lgn, lg_pt = (league sum of o_trip_pts)/lgn, lg_var = max((league sum of o_trip_pts_sq)/lgn - lg_pt^2, 0). td_own = (wsum(o_trip_td) + 25 lg_td)/(wsum(o_trips) + 25); td_alw = (wsum(a_trip_td) + 25 lg_td)/(wsum(a_trips) + 25); pt_own = (wsum(o_trip_pts) + 25 lg_pt)/(wsum(o_trips) + 25); pt_alw = (wsum(a_trip_pts) + 25 lg_pt)/(wsum(a_trips) + 25). tdt_rate_adj_pre = td_own - (opponent's td_alw in this game) + lg_td; ste_adj_pre = pt_own - (opponent's pt_alw) + lg_pt; ste_se_pre = sqrt(lg_var/(wsum(o_trips) + 25)).
TD split: s_rush, s_pass = sum of the team's o_rush_td, o_pass_td over its EARLIER rows in the SAME season (earlier by row order); p_rush, p_pass = the team's total o_rush_td, o_pass_td over its rows of season-1 (0 if none). rt = s_rush + p_rush, pt = s_pass + p_pass, n = rt + pt; LR, LP = league sums of o_rush_td, o_pass_td; Lt = LR + LP (NaN if 0). tdt_rush_share_pre = (rt + 30 LR/Lt)/(n + 30); tdt_pass_share_pre = (pt + 30 LP/Lt)/(n + 30).
cfb.pass_rate: lg_pr = (league sum of o_neu_pass)/(league sum of o_neu_n) (NaN if 0); pr_own = (wsum(o_neu_pass) + 100 lg_pr)/(wsum(o_neu_n) + 100); pr_alw = (wsum(a_neu_pass) + 100 lg_pr)/(wsum(a_neu_n) + 100). pr_neutral_pre = pr_own; pr_neutral_allowed_pre = pr_alw; pr_exp_pre = pr_own + (opponent's pr_alw) - lg_pr.
cfb.script_adjusted_pass_attempts: sapa_dropbacks_pre = EWMA(o_dropbacks); sal = EWMA(a_dropbacks); sapa_opp_allowed_pre = the opponent's sal; lg_db = (league sum of o_dropbacks)/(number of team rows with date < d) (NaN if none); sapa_exp_dropbacks_pre = sapa_dropbacks_pre + (the opponent's sal) - lg_db.
cfb.havoc: hv_def_pre = EWMA(a_havoc/a_scr); hv_off_allowed_pre = EWMA(o_havoc/o_scr); lg_hv = (league sum of o_havoc)/(league sum of o_scr); hv_def_adj_pre = hv_def_pre - (the opponent's hv_off_allowed_pre) + lg_hv.
cfb.goal_to_go_run_pass_mix: for each of n = o_gtg_n, r = o_gtg_run, rt = o_gtg_run_td, pn = o_gtg_pass_n, pt = o_gtg_pass_td: w_x = (sum of the team's x over its EARLIER rows in the same season) + 0.5 * (the team's total x over season-1, 0 if none). L(a, b) = (league sum of a)/(league sum of b), NaN if the denominator is 0. gtg_run_share_pre = (w_r + 40 L(r, n))/(w_n + 40); gtg_td_rate_run_pre = (w_rt + 40 L(rt, r))/(w_r + 40); gtg_td_rate_pass_pre = (w_pt + 40 L(pt, pn))/(w_pn + 40).
