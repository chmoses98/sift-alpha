Data (read-only): `/tmp/claude-0/blind/nba/espn/player_games_<season>.parquet` and `/tmp/claude-0/blind/nba/espn/shot_events_<season>.parquet` (all files). Use only pandas/numpy. ## Universe and ordering
* player_games rows with season_type == 'regular' and played == True. Key: game_id (string), `team` = nba_id (the PLAYER id, an integer), tm = team_id (the club). date = game_date_et. season_n = integer before the dash of `season`.
* Sort rows by (date, game_id, nba_id) (stable). "Earlier games of a player" = his earlier rows in that order. games_pre = number of the player's earlier rows (0 for his first).
* Team totals per (game_id, tm) over these rows: t_fga = sum fga, t_fta = sum fta. usg = fga + 0.44*fta; usg_share = usg / (t_fga + 0.44*t_fta).
* role: sr = per-player `started` (as 0/1 float) shifted by one row then pandas `ewm(halflife=15, min_periods=3).mean()`; role = 1.0 if sr >= 0.5 else 0.0; NaN if sr is NaN.
* lg_role(x): league mean of per-row value x over all rows with the SAME role value and date STRICTLY BEFORE this row's date (NaN values skipped; NaN if none or role is NaN).
* "per-player ewm" = `groupby(player).transform(lambda s: s.shift(1).ewm(...))`. "expanding" = shift(1) then expanding.
## Inputs and columns (27 columns in total)
### nba.heavy_minutes_tail_prob -> heavy38_rate_pre, heavy38_shr_pre, heavy38_n_pre
heavy38 = 1.0 if minutes >= 38 else 0.0 (NaN minutes -> 0.0). heavy38_rate_pre: from the player's previous up to 80 rows (most recent first, age 1 = the immediately previous row) the weighted mean with weight 0.5**(age/30), weights normalised to sum 1; NaN if fewer than 5 earlier rows. n_eff = min(games_pre, 80). heavy38_shr_pre = (n_eff*rate + 15*lg_role(heavy38)) / (n_eff + 15). heavy38_n_pre = sum of heavy38 over the previous up to 80 rows (NaN for the player's first row).
### nba.single_game_ceiling_tail -> p35_pre, p35_shr_pre, n35_pre, season_max_pts_pre
ge35 = 1.0 if pts >= 35 else 0.0. p35_pre = expanding mean of ge35 over all earlier rows, requiring at least 10 earlier rows (else NaN). p35_shr_pre = (games_pre*p35_pre + 30*lg_role(ge35)) / (games_pre + 30). n35_pre = expanding sum of ge35 over earlier rows (NaN for the first row). season_max_pts_pre = max of pts over the player's earlier rows in the SAME season_n (NaN if none).
### nba.points_upper_tail_rate -> ex14_rate_pre, ex17_rate_pre, ex20_rate_pre, tail_n_pre
cp = sum of pts over the player's earlier rows, cm = sum of minutes over earlier rows; ppm = cp/cm if cm > 0 (else NaN); m_g = ppm * (this row's minutes). A row is "base" if minutes >= 30 and m_g > 0. For k in 1.4, 1.7, 2.0: ex_k = 1.0 if pts >= k*m_g else 0.0, for base rows only (NaN otherwise). exK_rate_pre (names ex14, ex17, ex20) = expanding mean of ex_k over earlier rows (NaN skipped), requiring at least 5 non-NaN earlier values. tail_n_pre = number of earlier rows whose ex_1.4 is non-NaN (NaN for the first row).
### nba.fga_per_minute_by_shot_type -> a2_per36_pre, a3_per36_pre, fta_per36_pre
a2 = fga - fg3a. For att in (a2, fg3a, fta): num = per-player `s.shift(1).ewm(halflife=20, adjust=True).sum()` of att; den = same of minutes; lgm = lg_role(att/minutes) over rows with minutes > 0. Value = 36*(num + 300*lgm)/(den + 300) if den is not NaN and games_pre >= 3, else NaN. Names: a2_per36_pre, a3_per36_pre (att = fg3a), fta_per36_pre.
### nba.teammate_absence_shift -> tm_abs_dmin1_pre, tm_abs_dmin2_pre, tm_abs_dmin3_pre, tm_abs_n1_pre, tm_abs_n2_pre, tm_abs_n3_pre
Work per club tm over all seasons. The club's games = its distinct game_ids ordered CHRONOLOGICALLY by (date, then game_id as a tiebreak) (index i = 0,1,..); the date, not the game_id string, decides the order (round 2 clarification: round 1 sorted game_id strings and so did not match). M[i, p] = minutes of player p in game i if p has a row for that club and game, else NaN (players indexed by ascending nba_id within the club). For a row (game i, player j) with i >= 1: lo = max(0, i-10); tot[p] = sum over club games lo..i-1 of M (NaN as 0); set tot[j] = -1; rank players by (tot descending, index ascending); for k = 1,2,3 let x = the k-th ranked player; skip k if tot[x] <= 0. Over club games 0..i-1: f0 = first game index in which x has a non-NaN M; absent = (M[:,x] is NaN or < 5) and index >= f0; present = M[:,x] non-NaN and >= 5; mine = M[:,j]; a = absent and mine non-NaN; b = present and mine non-NaN. n_a = count(a). If n_a >= 3 and count(b) >= 3: tm_abs_dmin{k}_pre = (mean(mine[a]) - mean(mine[b])) * n_a/(n_a+15) and tm_abs_n{k}_pre = n_a; else both NaN.
### nba.first_basket_share -> fb_team_rate_pre, fb_team_shr_pre, fb_game_rate_pre, fb_game_shr_pre, usage_share_pre
shots = shot_events rows with season_type == 'regular' and is_shooting_play == True; shooter id sid = shooter_player_id (as float; equals nba_id). Field goals = rows with is_free_throw == False, ordered by (game_id, period asc, clock_seconds_remaining DESC, sequence asc) (stable); made = field goals with shot_made == True. fb_team = 1.0 for the sid of the FIRST made field goal of each (game_id, is_home) pair; fb_game = 1.0 for the sid of the first made field goal of the game. For each player row, fb_team / fb_game = 1.0 if flagged else 0.0, provided the game_id appears in `shots` at all (else NaN).
usage_share_pre = per-player ewm(halflife=30, min_periods=3).mean() of usg_share. gp = min(games_pre, 60). fb_team_rate_pre = per-player ewm(halflife=40, min_periods=5).mean() of fb_team; fb_team_shr_pre = (gp*rate + 10*usage_share_pre*1.0)/(gp+10). fb_game_rate_pre likewise of fb_game; fb_game_shr_pre = (gp*rate + 10*usage_share_pre*0.5)/(gp+10).
### nba.early_game_usage_first6 -> early_usg_share_pre, early_made_share_pre
Early rows = `shots` rows with period == 1 and clock_seconds_remaining >= 360 (both field goals and free throws). e_att(game, sid) = sum of u over early rows, u = 0.44 for is_free_throw == True rows else 1.0; e_made(game, sid) = number of early rows with is_free_throw == False and shot_made == True; missing (game, sid) -> 0.0 when the game is in `shots`, else NaN. Team early totals per (game_id, tm): _tea = sum of e_att over the club's player rows, _tem = sum of e_made. sp = per-player shift(1).ewm(halflife=25, adjust=True).sum() of e_att; st = same of _tea; early_usg_share_pre = (sp + 120*usage_share_pre)/(st + 120) if games_pre >= 10 else NaN. sm, stm = the same ewm sums of e_made and _tem; early_made_share_pre = sm/stm if stm > 0 and games_pre >= 10 else NaN.
