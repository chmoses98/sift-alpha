## Universe

Two rows per game: `team` = home_team_id and away_team_id (ints); opp = the other; date = game_date; gtype = game_type (2 regular season, 3 playoffs); home = True for the home row; gf/ga = own/opposing score; lpt = last_period_type as text. win = 1.0 if gf > ga else 0.0; beyond = 1.0 if lpt in (OT, SO); reg_win = win * (lpt == 'REG'); extra_win = win * beyond; row_win = win * (lpt != 'SO'). ## nhl.loser_point_rate (regular-season rows only) -> lp_beyond_pre, lp_win_extra_pre, lp_reg_win_pre, lp_pts_pg_pre, lp_reg_wins_season_pre, lp_row_season_pre
For team T, season s, date d: for X in (beyond, reg_win, extra_win, row_win, n=1 per game): c_X = sum over T's REGULAR-season games of season s with date < d; p_X = sum over ALL T's regular-season games of season s-1 (0 if none); w_X = c_X + 0.5*p_X; n = w_n. lg_beyond = mean of `beyond` over all regular-season team rows with date < d (all seasons; NaN if none).
pb = (w_beyond + 30*lg_beyond)/(n+30); pwe = (w_extra_win + 40*0.5)/(w_beyond + 40); prw = w_reg_win/n; pts = 2*prw + 2*pb*pwe + 1*pb*(1-pwe).
lp_beyond_pre = pb, lp_win_extra_pre = pwe, lp_reg_win_pre = prw, lp_pts_pg_pre = pts, each NaN when n < 10. lp_reg_wins_season_pre = c_reg_win and lp_row_season_pre = c_row_win (this season only, 0 if none; defined for every regular-season row, no n requirement).
## nhl.pair_attempt_volume (regular-season rows only) -> att_off60_pre, att_def60_pre, att_exp_att60_pre, att_proj_5v5_min_pre, att_exp_game_att_pre
From the moneypuck file (drop duplicate (game_id, team_id, situation)): for each regular-season team row take situation '5on5': shotAttemptsFor, shotAttemptsAgainst, iceTime (seconds); situation '5on4' iceTime = pp; '4on5' iceTime = pk (NaN->0 when missing). ice = iceTime if > 0 else NaN. off60 = shotAttemptsFor/(ice/3600); def60 = shotAttemptsAgainst/(ice/3600); pp_min = pp/60; pk_min = pk/60.
Per (team, date) take the mean of each of off60, def60, pp_min, pk_min (NaN skipped). Per team, along its distinct regular-season dates in order: X_pre = `shift(1).ewm(halflife=H, min_periods=5).mean()` with H = 164 for off60 and def60, H = 40 for pp_min and pk_min; attach to the team rows of that date.
lg(d) = mean of off60 over all regular-season rows (non-NaN) with date < d. home_adj(d) = mean over the same rows of sign*off60 where sign = +1 for home rows, -1 for away rows. o_def, o_off, o_pp, o_pk = the OPPONENT's (same game) def60_pre, off60_pre, pp_min_pre, pk_min_pre.
att_off60_pre = off60_pre; att_def60_pre = def60_pre; exp_att60 = lg + (off60_pre - lg) + (o_def - lg) + (+0.5 if home else -0.5)*home_adj -> att_exp_att60_pre; att_proj_5v5_min_pre = 60 - ((pp_min_pre + o_pk)/2 + (pk_min_pre + o_pp)/2); att_exp_game_att_pre = (exp_att60 + opponent's exp_att60) * att_proj_5v5_min_pre / 60.
## nhl.rating_posterior_uncertainty (regular-season rows only) -> kf_rating_mean_pre, kf_rating_sd_pre
y = scoreVenueAdjustedxGoalsFor - scoreVenueAdjustedxGoalsAgainst from the moneypuck row with situation 'all' of that (game_id, team) (NaN if missing). Process regular-season dates in ascending order with per-team state (mean, var) and per-team last season. For each date: for every team playing that date: if never seen: mean=0, var=0.25**2; elif its last season differs from this season: mean = 0.5*mean, var = 0.25**2; set last season. pre[team] = (mean, var) recorded for that team's rows of the date: kf_rating_mean_pre = mean, kf_rating_sd_pre = sqrt(var).
s2 = (sum of squared residuals so far)/(number of residuals so far) if at least 100 residuals exist from EARLIER dates, else 1.5**2. For each row of the date (in row order) with y not NaN: (mi,vi)=pre[team]; (mj,vj)=pre[opp]; vpred = vi + 0.02**2; R = s2 + vj; z = y + mj; K = vpred/(vpred+R); candidate new mean = mi + K*(z - mi), new var = (1-K)*vpred; residual = y - (mi - mj). After ALL rows of the date are processed apply the new states and add each residual (and its square, count) to the running sums. A team that played that date but produced no update has var = pre var + 0.02**2 (mean unchanged).
## Playoff series (playoff rows only; gtype == 3)
One game row per game_id (take the home team's row). Series key = (season, min(team,opp), max(team,opp)); a = the smaller team id, b = the larger. Order a series' games by (date, game_id); gno = 1,2,...; w_a = 1 if team a won that game (home team won and home is a, or home team lost and the away team is a); w_b = 1 - w_a. wa_pre, wb_pre = wins of a, b in EARLIER games of the series; ot = beyond of the game; ot_pre = number of OT/SO games earlier in the series; total = gf + ga of the game; state label = "{max(wa_pre,wb_pre)}-{min(wa_pre,wb_pre)}"; elim = 1 if max(wa_pre,wb_pre) == 3 else 0.
A series is DONE when one side has 4 wins over all its games; its end date = date of its last game, n = number of games, k = number of OT/SO games.
For each game date d: ge = all playoff game rows (all series, one row per game) with date < d. p = mean of ot over ge (NaN if empty). e = done series with end date < d, N = len(e). rho: if N >= 5 and 0 < sum(k) < sum(n): pe = sum(k)/sum(n); Q = sum((k - n*pe)**2)/(pe*(1-pe)); rho = (Q - sum(n))/sum(n*(n-1)); else NaN. rho_s = (N*(rho if rho is not NaN else 0.05) + 40*0.05)/(N+40) if N >= 5 else NaN. pm = mean of total over ge; ns, ss = count and sum of total over ge rows with the same state label as this game; factor = ((ss + 15*pm)/(ns + 15))/pm (NaN if ge empty).
Lag logit (one fit per season s from playoff games of EARLIER seasons): gd(season, team) = mean of (gf - ga) over that team's regular-season rows that season. For each game row: x_gap = gd(home team) - gd(away team) (NaN if either missing); x_lag = 0 for gno == 1, else +1 if the home team of THIS game won the previous game of the series and -1 if it lost it; y = win (home team won this game). Training rows = games with season < s and non-NaN x_gap; if fewer than 300, coefficient NaN. Else X = [1, x_gap, x_lag], penalty lam = [0, 0, 1/0.15**2], b = 0, repeat 30 times: pr = 1/(1+exp(-X b)); grad = X'(y-pr) - lam*b; H = X' diag(pr(1-pr)) X + diag(lam); b = b + solve(H, grad). coef = b[2]; se = sqrt(inv(H)[2,2]) with H from the last iteration. Every game of season s gets that (coef, se).
Team-perspective columns for each playoff team row: ser_ot_games_pre = ot_pre; ser_ot_p_hist_pre = p; ser_ot_rho_pre = rho_s; ser_ot_nseries_pre = N; ser_state_factor_pre = factor; ser_state_n_pre = ns; ser_wins_pre = wins of THIS team earlier in the series; ser_opp_wins_pre = wins of the opponent; ser_elim_pre = elim; ser_lag_result_pre = x_lag if the team is the home team of the game else -x_lag; ser_lag_coef_pre = coef; ser_lag_se_pre = se.
