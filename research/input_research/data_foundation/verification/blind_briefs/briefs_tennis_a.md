Data (read-only): `/tmp/claude-0/blind/tennis/atp_matches_<year>.csv.gz` and `wta_matches_<year>.csv.gz` (years 2000-2026; Jeff Sackmann match files). Use only pandas/numpy. ## Universe and keys
* Read every file (file names sorted, rows in file order), tour = the file-name prefix ('atp'/'wta'). Drop rows with a null tourney_date, winner_id or loser_id. date = tourney_date parsed as YYYYMMDD (tournament START date). game_id = `"{tour}|{tourney_id}|{match_num}|{k}"` where match_num is the integer value and k = the number of EARLIER rows (in the order read) with the same `"{tour}|{tourney_id}|{match_num}"` string (0 for the first). Player key = `"{tour}:{id}"` with id an integer (e.g. `atp:104925`).
* Output = TWO rows per match: (game_id, team = winner key) and (game_id, team = loser key). Match-level columns are identical on both rows; the columns marked PLAYER use that row's own player.
* DATE BATCHING: every statistic for a match uses ONLY matches with tourney_date STRICTLY EARLIER than its own tourney_date (same tour or pooled as stated), never anything dated the same day.
* Sort the matches (the "Elo order") by (tour, date, tourney_id, match_num, game_id) (stable); ties in later "last 60 wins" style lists follow this order.
## Walk-forward Elo
Per tour, process each distinct date as ONE batch in Elo order. Overall rating e[player] and per-surface rating es[(player, surface)], all initial 1500, surface valid only if exactly one of 'Hard', 'Clay', 'Grass', 'Carpet' (otherwise there is no surface rating for that match). For every match of the batch record the PRE-batch ratings (ew, el = overall of winner, loser; sw, sl = surface ratings, NaN if the surface is invalid). Matches whose score contains 'W/O' do not update. Otherwise p = 1/(1+10**(-(ew-el)/400)); delta = 32*(1-p); winner +delta, loser -delta (summed over the batch, applied AFTER the whole batch); the surface ratings update the same way with their own pre-batch ratings (p_s from sw, sl) when the surface is valid.
Combined rating r = 0.5*(overall + surface) if the surface rating exists else overall. p_w = 1/(1+10**(-(rw-rl)/400)) (probability of the WINNER, from pre-match ratings only). Favourite = the winner if rw > rl or (rw == rl and the winner key < the loser key as strings), else the loser: fav_is_w. p_fav = p_w if fav_is_w else 1-p_w. bin = min(floor(p_fav*20), 19) (5-point bins); p_win_bin = min(floor(p_w*20), 19).
## Score parsing
Parse `score`: blank/non-text -> unusable; contains 'W/O' -> walkover (unusable); flag RET if it contains 'RET', else DEF if it contains 'DEF', else unusable if it contains 'ABD' or 'UNP'. Tokens = whitespace-split pieces other than RET, DEF, ABD, UNP; every token must match `^(\d+)-(\d+)(\(\d+\))?$` (first number = winner's games) else unusable. complete_set(a,b) = (max>=6 and max-min>=2) or (max==7 and min in (5,6)).
* If unusable or no tokens: no outcome fields (ok = False, ret = False).
* RET or DEF: ret = True, comp_sets = number of complete tokens, gw = sum of first numbers, gl = sum of second numbers (all tokens), d_w = gw - gl; ok = False.
* Otherwise: need = best_of//2 + 1; ws = #tokens with a>b, ls = #tokens with b>a; require max(ws,ls) == need and all tokens complete, else unusable. If good: ok = True, n_sets = number of tokens, straight = 1 if ls == 0, decider = 1 if n_sets == best_of, d_w = gw - gl, tb = 1 if any token has max == 7 and min == 6, gw, gl as sums.
## Windowed cell statistic ("W")
W(key, window, value columns): for each match, over matches with the same key tuple (a missing key part counts as its own value) and date d_m with date - window_days <= d_m < date (no lower limit if window is none) take, per value column, sum and count of the NON-NaN values. Shrunk value (S, k): cm = cell sum/cell count, pm = pool sum/pool count, w = cell count/(cell count + k); result = NaN if the pool count is 0; else w*cm + (1-w)*pm if cell count > 0; else pm.
## Inputs and columns
### ten.straight_set_share_curve -> ssc_straight_pre, ssc_decider_pre, ssc_straight_given_favwin_pre, ssc_n_pre
Values (ok matches only, NaN otherwise): straight; decider; straight restricted to matches where fav_is_w (NaN otherwise). cell key (tour, best_of, surface, bin), pool key (tour, best_of, surface), window 3650 days, S with k = 40 per column. ssc_n_pre = cell count of the first column.
### ten.set_count_distribution_by_edge -> scd_p2_pre, scd_p3_pre, scd_p4_pre, scd_p5_pre, scd_mean_sets_pre
Values (ok matches): 1/0 indicators of n_sets == 2,3,4,5 and n_sets itself; same cell/pool/window, S with k = 40.
### ten.game_margin_pmf_calibration -> gmc_mean_d_pre, gmc_p_gt15_pre, gmc_p_gt35_pre, gmc_p_gt55_pre, gmc_p_gt75_pre
d_fav = d_w if fav_is_w else -d_w (ok matches). Values: d_fav, and indicators d_fav > 1.5, 3.5, 5.5, 7.5. Same cell/pool/window, S with k = 50.
### ten.win_margin_conversion_curve -> wmc_p_gt15_pre, wmc_p_gt35_pre, wmc_p_gt55_pre, wmc_p_neg_pre
Values (ok matches): indicators d_w > 1.5, 3.5, 5.5 and d_w < 0. Cell key (tour, best_of, bin), pool key (tour, best_of), window 3650 days, S with k = 60.
### ten.retirement_timing_profile -> rtp_p_before_set1_pre, rtp_p_before_set2_pre, rtp_p_before_set3_pre, rtp_p_retiree_trailing_pre, rtp_mean_games_pre, rtp_p_d_gt15_pre
Round group: R128, R64, R32 -> early; R16, QF -> mid; SF, F, RR, BR -> late; anything else (including missing) -> late. Values for ret matches only (NaN otherwise): comp_sets == 0; comp_sets <= 1; comp_sets <= 2; gl < gw (retiring player = loser is trailing); gw + gl; d_w > 1.5. Cell key (tour, best_of, round group), pool key (tour), NO window, S with k = 30.
### ten.retirement_margin_state -> rms_p_gt15_fav_retires_pre, rms_p_gt15_dog_retires_pre, rms_mean_d_fav_retires_pre, rms_mean_d_dog_retires_pre
For ret matches: the retiring player is the loser; fav_retires = (not fav_is_w). Key (tour), no window. Columns: (1) indicator d_w > 1.5 over ret matches where fav_retires; (2) the same where not fav_retires; (3) d_w over ret matches where fav_retires; (4) d_w where not fav_retires; (5) indicator d_w > 1.5 over all ret matches. rms_p_gt15_fav_retires_pre = S(cell = column 1, pool = column 5, k = 30); rms_p_gt15_dog_retires_pre = S(cell = column 2, pool = column 5, k = 30); rms_mean_d_fav_retires_pre = sum(3)/count(3) (NaN if count 0); rms_mean_d_dog_retires_pre = sum(4)/count(4).
### ten.tiebreak_base_rate_by_event -> tbe_tb_rate_pre, tbe_ss_rate_pre, tbe_n_eff_pre
Values (ok matches): tb; straight. Event key (tour, tourney_name), window 1095 days, EXPONENTIALLY WEIGHTED: each earlier match weighs 2**(-(date - d_m)/548) with the day difference in days; ne = sum of weights over non-NaN values, er = weighted sum/ne. Tour rate tr = plain mean over matches with key (tour, best_of) in the same 1095-day window (NaN if none). Value = (ne*er + 60*tr)/(ne + 60) if ne > 0 else tr. tbe_n_eff_pre = ne of the tb column (0 if none).
### ten.venue_speed_history -> vsh_ace_dev_pre, vsh_hold_dev_pre, vsh_tb_dev_pre, vsh_games_dev_pre, vsh_n_pre
Per match: svpt = w_svpt + l_svpt; aces = w_ace + l_ace; svg = w_SvGms + l_SvGms; bpl = (w_bpFaced - w_bpSaved) + (l_bpFaced - l_bpSaved) (any NaN part -> NaN). Values: v0 = aces if svpt > 0 else NaN; v1 = svpt if svpt > 0 else NaN; v2 = bpl if svg > 0 else NaN; v3 = svg if svg > 0 else NaN; v4 = tb (ok matches); v5 = gw + gl (ok matches). Window 1095 days, unweighted sums/counts (NaN skipped per column) for event key (tour, tourney_name) and for tour-surface key (tour, surface). For each: ace = sum(v0)/sum(v1); hold = 1 - sum(v2)/sum(v3); tbr = sum(v4)/count(v4); games = sum(v5)/count(v5) (NaN if the denominator is 0). n = event count(v4); w = n/(n+100). vsh_ace_dev_pre = w*(event ace - tour-surface ace), vsh_hold_dev_pre = w*(event hold - ts hold), vsh_tb_dev_pre = w*(event tbr - ts tbr), vsh_games_dev_pre = w*(event games - ts games) (NaN whenever any part is NaN); vsh_n_pre = n.
### ten.player_set_drop_propensity -> psd_resid_pre (PLAYER), psd_n_pre (PLAYER)
exp_ss = plain mean of straight over ok matches with key (tour, best_of, p_win_bin) and window 3650 days (NaN if none). res = straight - exp_ss for ok matches (NaN if either is NaN or not ok). For a match with date d and a given player: take that player's WIN matches (as winner) that have a non-NaN res and date < d, ordered chronologically (date, then Elo order); keep the last 60; if none: psd_resid_pre = NaN, psd_n_pre = 0. Else n = how many were kept, weights 0.5**((d - date_m)/365) (days), psd_resid_pre = (sum w*res / sum w) * n/(n+25), psd_n_pre = n. Both rows of a match use their own player.
### ten.round_upset_calibration -> rup_resid_pre, rup_n_pre
seed numbers sw, sl = numeric winner_seed, loser_seed (NaN if non-numeric/missing). seed_bin = if both present: 'd1-3' if |sw-sl| <= 3, 'd4-8' if <= 8, else 'd9+'; elif exactly one present: 'one'; else 'none'. Value r = (1 if fav_is_w else 0) - p_fav for matches that are ok OR ret (NaN otherwise). Key (tour, round as text, seed_bin), window 3650 days: n = count, mean = sum/n; rup_resid_pre = mean * n/(n+100) (NaN if n == 0), rup_n_pre = n (0 if none).
