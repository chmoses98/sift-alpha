Columns used: tourney_id, tourney_name, tourney_date, surface, tourney_level, round, match_num, winner_id, loser_id, winner_ioc, loser_ioc. Use only pandas/numpy. ## Universe and keys
* Read every file (file names sorted, rows in file order), tour = file-name prefix ('atp'/'wta'). Drop rows with null tourney_date, winner_id or loser_id. date = tourney_date as YYYYMMDD (tournament START date). game_id = `"{tour}|{tourney_id}|{match_num}|{k}"`, match_num as integer, k = number of EARLIER rows (in read order) with the same `"{tour}|{tourney_id}|{match_num}"` string. Player key `"{tour}:{id}"`, id integer.
* Output two rows per match: (game_id, team = winner key) and (game_id, team = loser key). A column named PLAYER uses that row's own player; others are identical on both rows.
## Editions
Matches with tourney_level == 'G' define majors. An edition = (tour, tourney_id); start = its date; name = its tourney_name; surface = its surface (first row); champion = the winner key of its round == 'F' match (none if no such row). done = start + 15 days. Per tour sort editions by (start, tourney_id). All "earlier editions" statements are per tour. Round index: R128=1, R64=2, R32=3, R16=4, QF=5, SF=6, F=7, anything else 0. reach[(tour, tourney_id, nation)] = max over the edition's matches of: for the winner's nation (winner_ioc, text) round index + 1 if the round is F else round index; for the loser's nation (loser_ioc) round index.
Process each (tour, date) of matches. k = number of that tour's editions with done STRICTLY BEFORE this date (editions sorted by start so done is sorted).
## ten.major_winner_concentration -> mwc_hhi_pre, mwc_top2_pre, mwc_n_pre, mwc_player_share_pre (PLAYER)
For EVERY match of the tour on that date: last = the k most recent completed editions, at most 12, most recent first. If none: mwc_hhi_pre = mwc_top2_pre = NaN, mwc_n_pre = 0, mwc_player_share_pre = 0.0. Else edition i (0 = most recent) has weight 0.9**i; each champion's share = (sum of weights of the editions he won)/(sum of ALL weights of the last editions; editions without a champion add weight but no share). mwc_hhi_pre = sum of squared shares; mwc_top2_pre = sum of the two largest shares (just the largest if only one champion); mwc_n_pre = number of editions used; mwc_player_share_pre = the row player's share (0 if he is not a champion among them).
## ten.slam_to_slam_carryover -> s2s_repeat_rate_pre, s2s_n_pairs_pre, s2s_gap_bucket, s2s_surface_change, s2s_prev_champ (PLAYER)
Defaults for every match: s2s_repeat_rate_pre = NaN, s2s_n_pairs_pre = 0, s2s_gap_bucket = NaN, s2s_surface_change = NaN, s2s_prev_champ = 0.
Applies only if k >= 1 AND some edition j of that tour has start == this date (take the first such edition in the sorted order) with j >= 1; for all matches of that tour on that date: s2s_prev_champ = 1 if the row player is the champion of edition j-1 else 0. Gap of edition i relative to i-1: gap_i = (start_i - (start_{i-1} + 13 days)) in days; bucket = 1 if gap <= 21, 2 if <= 42, else 3. Pairs: for i = 1..k-1 (editions completed before this date and their predecessors): repeat = 1 if champion_i exists and equals champion_{i-1}; per bucket count repeats r_b and pairs n_b; totals allr, alln; pooled = allr/alln. For matches that are themselves at a major (tourney_level == 'G') among those matches: bucket b = bucket of gap_j; s2s_gap_bucket = b; s2s_n_pairs_pre = n_b; s2s_repeat_rate_pre = (r_b + 8*pooled)/(n_b + 8) if alln > 0 else NaN; s2s_surface_change = 1.0 if surface_j != surface_{j-1} else 0.0. (Other tournaments on that date keep only s2s_prev_champ.)
## ten.home_slam_depth_prior -> hsdp_nat_r16_pre, hsdp_nat_qf_pre, hsdp_nat_sf_pre, hsdp_nat_f_pre, hsdp_home (all PLAYER)
Defaults: the four frequency columns NaN, hsdp_home 0.0. Applies to ALL matches of the tour on a date equal to the start of some edition j (first such): host = the first of ('Australian Open' -> AUS), ('Roland Garros' -> FRA), ('French Open' -> FRA), ('Wimbledon' -> GBR), ('US Open' -> USA) whose text is contained in name_j (none -> no host and nothing is set). hsdp_home = 1.0 if the row player's nation (winner_ioc for the winner row, loser_ioc for the loser row) equals the host. past = the last (most recent) 15 editions i < j of this tour whose host (same rule) equals this host and with done_i < this date. If past is non-empty: weight wt_i = 0.5**(age_i/6) with age_i = (date - start_i)/365 days (float); for threshold t in R16 = 4, QF = 5, SF = 6, F = 7: frequency = sum_i wt_i*[reach(tour, tourney_id_i, nation) >= t (0 if absent)] / sum wt_i, for the row player's nation (NaN if the nation is missing/non-text). Columns hsdp_nat_r16_pre, hsdp_nat_qf_pre, hsdp_nat_sf_pre, hsdp_nat_f_pre.
