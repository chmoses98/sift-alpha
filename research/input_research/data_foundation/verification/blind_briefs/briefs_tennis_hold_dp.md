## Universe and keys

Player key `"{tour}:{id}"` (id as integer). Output two rows per match: (game_id, winner key) and (game_id, loser key).
## Serve-point-win estimate
A match is USABLE if score does not contain 'W/O', w_svpt>0, l_svpt>0 and w_1stWon, w_2ndWon, l_1stWon, l_2ndWon are all non-null. For a usable match and a player P (opponent O): s_won = P's (1stWon+2ndWon), s_pts = P's svpt, r_won = O's svpt - O's (1stWon+2ndWon), r_pts = O's svpt. Unusable matches contribute nothing (NaN).
For a row with date d use only matches with date STRICTLY EARLIER than d and date >= d - 1095 days. Player P's rows (as winner or loser, same player key) are weighted w = 0.5 ** ((d - d_m in days)/365). sp = sum(w*s_won)/sum(w*s_pts); rr = sum(w*r_won)/sum(w*r_pts) over P's usable earlier matches in the window (NaN if none). t = UNWEIGHTED sum(s_won)/sum(s_pts) over ALL usable earlier same-tour matches in the window, both players' rows pooled (NaN if none).
Adjusted serve-point-win of P against O (same match, same date d, O's own sp/rr computed identically as of d): spw = clip(sp_P + (rr_O - (1 - t)), 0.30, 0.90); opp_spw = clip(sp_O + (rr_P - (1 - t)), 0.30, 0.90). If any input is NaN the row's columns are all NaN. Both rows of a match use the same t (same tour).
NUMERICAL REQUIREMENT: 1e-9 relative. Compute weights directly per (row, earlier match) pair as `0.5 ** (days/365)`, float64; no cumulative-sum differencing across keys.
## Game, set and tiebreak (A = the row's player, B = opponent; pA = spw, pB = opp_spw)
hold(p) = p^4 (1 + 4q + 10 q^2) + 20 p^3 q^3 * p^2/(1 - 2 p q), q = 1-p. hA = hold(pA), hB = hold(pB).
Tiebreak, first to 7 points and win by 2. Let S1 be the player serving the first point. Point k (1-indexed) is served by S1 if k==1 or floor((k-2)/2) is odd, else by the other player. A server wins a point he serves with his spw. P(S1 wins the tiebreak) = f(0,0) where f(x,y) (x,y = points of S1 and the other) is 1 if x==7 and y<=5, 0 if y==7 and x<=5, and a/(a+b) at 6-6 with a = pS1*(1-pS2), b = (1-pS1)*pS2 (pS1, pS2 = the two players' spw), else p*f(x+1,y)+(1-p)*f(x,y+1) where p = P(S1 wins point x+y+1).
Set: games alternate service. The FIRST SERVER of the set is A in one case and B in the other; compute both and average them (weight 1/2 each). Game number g (0-indexed) is served by the first server when g is even. A wins a game with probability hA if A serves, else 1-hB. The set ends when a player reaches 6 games with the other at <=4, or reaches 7 with the other at 5; at 6-6 a tiebreak is played whose first point is served by the set's first server (A wins it with the probability from the tiebreak recursion for that server). Total games: 6,7,8,9,10 (6-0..6-4 either way), 12 (7-5), 13 (7-6). P(tiebreak) = P(6-6). w = P(A wins the set) (average over the two first-server cases, tiebreak winner included). Margin D = A games - B games (a 7-6 set has |D|=1). e1 = E[D], e2 = E[D^2], v1 = e2 - e1^2 (each averaged over the two first-server cases).
