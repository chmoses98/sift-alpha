Data (read-only): `/tmp/claude-0/blind/tennis/atp_matches_<year>.csv.gz` and `wta_matches_<year>.csv.gz` (2000-2026; Sackmann). Columns used: tourney_id, tourney_date, match_num, winner_id, loser_id, score, w_svpt, w_1stIn, w_2ndWon, l_svpt, l_1stIn, l_2ndWon. Use only pandas/numpy. ## Universe and keys
Read every file (sorted names, rows in file order), tour = file-name prefix ('atp'/'wta'). Drop rows with null tourney_date, winner_id or loser_id. date = tourney_date as YYYYMMDD (tournament START date). game_id = `"{tour}|{tourney_id}|{match_num}|{k}"` (match_num integer; k = number of EARLIER rows in read order with the same `"{tour}|{tourney_id}|{match_num}"` string). Player key `"{tour}:{id}"` (integer id). Output two rows per match: (game_id, winner key) and (game_id, loser key).
DATE BATCHING: a match uses ONLY matches with tourney_date STRICTLY EARLIER than its own tourney_date, and dated at most 1095 days before it (date - 1095 days <= d_m < date).
## Usable player-match rows
Second-serve points of a player in a match: pts2 = svpt - 1stIn; second-serve points won = 2ndWon (w_ columns for the winner, l_ for the loser). A MATCH is usable if the score does not contain 'W/O', both pts2 values are > 0 and both w_2ndWon and l_2ndWon are non-null (NaN anywhere else makes pts2 NaN -> not usable). For a usable match each of its two players has: s_pts = own pts2, s_won = own 2ndWon, r_pts = opponent's pts2, r_won = opponent's pts2 minus opponent's 2ndWon (the points this player won while RETURNING second serves).
## ten.second_serve_vulnerability -> ssv_2nd_won_pre, ssv_ret2_won_pre, ssv_adj_2nd_won_pre, ssv_pair_idx_pre
For a match at date d and a player P (and his opponent O): over P's earlier usable matches in the window, with weight w = 0.5 ** ((d - d_m in days)/365): ssv_2nd_won_pre = sum(w*s_won)/sum(w*s_pts); ssv_ret2_won_pre = sum(w*r_won)/sum(w*r_pts) (NaN if the denominator is empty/0). Same two quantities for O (call o_ret2 = O's ssv_ret2_won_pre). Tour mean tm2 = sum(s_won)/sum(s_pts) over ALL usable player-match rows of the same TOUR in the window (both players of every match, unweighted). ssv_adj_2nd_won_pre = ssv_2nd_won_pre(P) + (o_ret2 - (1 - tm2)). ssv_pair_idx_pre = (ssv_2nd_won_pre(P)/tm2) * (o_ret2/(1 - tm2)). All NaN whenever any needed part is NaN.
NUMERICAL REQUIREMENT: compared to 1e-9 relative; compute the weights per (match, earlier match) pair directly as 0.5 ** (days/365) in float64; do not use cumulative-sum differencing across keys or 2**(large) rescaling.
