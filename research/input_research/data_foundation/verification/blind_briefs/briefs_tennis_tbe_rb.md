# Blind re-implementation brief: tennis event tiebreak / straight-set base rate split by round and best_of (1 catalog input, 3 new columns)

Data (read-only): `BLIND_DIR/tennis/atp_matches_<year>.csv.gz` and `wta_matches_<year>.csv.gz` (2000-2026; Sackmann). Columns used: tourney_id, tourney_name, tourney_date, best_of, round, match_num, winner_id, loser_id, score. Use only pandas/numpy. Do NOT read anything under /home/user or any repository clone. Implement from this text alone; RECORD every ambiguity you resolve.

## Universe and keys
Read every file (sorted names, rows in file order), tour = file-name prefix. Drop rows with null tourney_date, winner_id or loser_id. date = tourney_date as YYYYMMDD (tournament START date). game_id = `"{tour}|{tourney_id}|{match_num}|{k}"` (match_num as integer; k = number of EARLIER rows (read order) with the same `"{tour}|{tourney_id}|{match_num}"` string). Player key `"{tour}:{id}"` (id as integer). Output two rows per match: (game_id, winner key) and (game_id, loser key); both rows carry identical values.
## Score parsing
Blank/non-text score -> unusable; contains 'W/O' -> unusable; flag RET if it contains 'RET', else DEF if 'DEF', else unusable if it contains 'ABD' or 'UNP'. Tokens = whitespace-split pieces other than RET, DEF, ABD, UNP; each must match `^(\d+)-(\d+)(\(\d+\))?$` (first number = winner's games) else unusable. complete_set(a,b) = (max>=6 and max-min>=2) or (max==7 and min in (5,6)). A match is OK only if it has no RET/DEF flag, is usable, need = best_of//2+1, ws = #tokens with a>b, ls = #tokens with b>a, max(ws,ls) == need and every token is complete (a missing best_of makes it not OK). For OK matches: tb = 1 if any token has max == 7 and min == 6 else 0; straight = 1 if ls == 0 else 0. Values are NaN for matches that are not OK.
## ten.tiebreak_base_rate_by_event, split by round and best_of -> tbe_tb_rate_rb_pre, tbe_ss_rate_rb_pre, tbe_n_eff_rb_pre
For a match with date d use only matches with date STRICTLY EARLIER than d and date >= d - 1095 days (the window). EVENT-ROUND-FORMAT key = (tour, tourney_name, round, best_of); a null round, tourney_name or best_of is a key value of its own (null equals null) and matches only other nulls. Each such earlier match m with the same key weighs w = 0.5 ** ((d - d_m in days)/548); ne = sum of w over those matches whose value of the column is not NaN, er = sum(w*value)/ne. ROUND-FORMAT TOUR rate tr = plain (unweighted) mean of the column over earlier matches in the same window with key (tour, round, best_of) (same null rule) and a non-NaN value; NaN if there is none. Value = (ne*er + 60*tr)/(ne + 60) if ne > 0 else tr (NaN when tr is NaN too). tbe_tb_rate_rb_pre uses the tb column, tbe_ss_rate_rb_pre uses straight; tbe_n_eff_rb_pre = ne of the tb column (0.0 if no earlier same-key match with a value).
NUMERICAL REQUIREMENT: results are compared to 1e-9 relative. Compute the weights directly per (match, earlier same-key match) pair as `0.5 ** (days/548)` and sum them with float64; do NOT use cumulative-sum differencing across keys or any 2**(large) rescaling trick (those lose precision).
